# 护目镜佩戴识别需求

更新日期：2026-10-22（北京时间）。本页记录当前任务；历史日志仅用于审计。

## 已确认契约

| 项目 | 当前要求 |
| --- | --- |
| 任务 | 静态头部裁剪头像的二分类 |
| 输出 | 每张头像的佩戴状态；不输出位置框 |
| 佩戴 | 可辨识的防护镜正确覆盖眼部 |
| 未佩戴 | 无防护镜、普通眼镜、太阳镜、额头/头顶佩戴 |
| 无法判断 | 排除出监督样本，不强行标未佩戴 |
| 首版输入 | 图片或图片目录，不增加视频、摄像头、身份识别或自动头部检测 |
| 当前授权 | 数据准备后，按确认流程修正日志/补齐分类入口、2轮短跑、通过后基线训练，最后一次冻结测试；不修改当前数据与划分 |
| 依赖 | 必要时在项目虚拟环境安装；本轮已有依赖足够 |
| 版本 | 保留独立日志、提交和v0.1.0，按已有授权普通push；真实图像及权重不上传 |

类别ID为`not_wearing_goggles=0`、`wearing_goggles=1`，普通眼镜不能因上游标为glasses/goggles就成为正例。图片只能支持外观判断，不能认证防护等级。具体裁剪、排除和来源组规则已按[数据处理方案](data_processing_plan.md)执行。
