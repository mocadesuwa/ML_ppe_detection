更新日期：2026-10-14。阶段：旧任务清理与静态图片入口整理完成，护目镜模型尚未适配。输入方向是头部裁剪头像，是否输出位置框待确认；以[需求清单](goggles_requirements.md)为当前任务依据。

## 1. 代码如何组织

| 文件 | 当前职责 |
| --- | --- |
| `src/common.py` | 路径、配置、来源哈希、数据指纹、质量核查及实验目录等共享逻辑 |
| `src/import_data.py` | 导入本地ZIP，检查路径、碰撞和覆盖，保留压缩包与来源记录；不联网 |
| `src/prepare_dataset.py` | 显式配置的VOC到YOLO转换、去重、来源分组和固定划分 |
| `src/check_dataset.py` | 检测数据的标签、清单和划分检查，生成抽查拼图 |
| `src/review_dataset.py` | 将已实际完成的人工核查绑定到数据指纹 |
| `src/environment.py` | 查询Python、现有依赖与GPU环境 |
| `src/train.py` | 显式配置的检测训练入口，`--dry-run`只打印计划 |
| `src/evaluate.py` | 显式权重和数据配置的检测评价、类别与训练来源核查 |
| `src/predict.py` | 静态图片预检、逐张检测、JSONL与成功/失败记录 |
| `scripts/find_related_images.py` | 对显式来源生成相似候选，不自动决定身份或来源组 |
| `scripts/preflight_training.py` | 显式检测配置的无梯度运行预检；本轮未运行 |
| `legacy/mask/` | 口罩三类配置、逐项决策、来源组与专用核查/派生脚本 |

`prepare/check/review/train/preflight`仍包含检测任务的约束，`predict`仍要求检测模型。保留这些可复用实现不代表已选定护目镜路线；若最终采用分类，需要调整这些契约、标注和指标，不增加一套未经要求的双模式框架。

## 2. 本轮删除和隔离了什么

- 删除自动访问固定口罩下载URL的代码和下载进度/超时分支，原`src.download_data`改为`src.import_data`，不保留误导性的旧入口别名。
- 取消准备/训练/预检的默认配置、核查/评价的默认数据和预测/评价的默认权重，避免无参数调用落到旧口罩任务。
- 移出活动目录中写死口罩类别的脚本和五份配置/决策文件，保留在`legacy/mask/`供历史复现和累计回归。
- 图片预测删除视频格式集合、每源帧号及视频计数；目录只筛选直接包含的支持图片，逐张交给后端，不把整个混合目录交给后端扫描。

原始数据、派生数据、冻结划分、权重和Git历史均保留。本轮不下载、裁剪、重标注或训练真实数据。

## 3. 本地ZIP导入约定

`python -m src.import_data`必须提供`--archive`、`--output`和`--source-url`。来源URL只用于记录，不自动核实许可或访问网页。

导入保留原有解压保护，拒绝覆盖非空目录、路径越界、路径碰撞及特殊文件。来源记录写在目标目录同级的`<目录名>.source.json`，不覆盖ZIP内部可能存在的`source.json`；记录存在时拒绝覆盖。导入前后检查压缩包哈希，许可核查仍记为未完成。

## 4. 图片预测结果（format_version=2）

- 支持JPG/JPEG、PNG、BMP和静态WebP；单文件视频/动画、空文件、无法校验的图片在模型加载前报错。目录忽略不支持的文件且不递归，筛选后没有图片时报错。
- 图片检查与推理逐张进行，不一次加载整个数据集。当前只校验可读取性及静态格式，不能自动认定输入已正确裁成头部头像。
- 每张结果包含`source`、从0开始的`image_index`、`image_size`及`detections`；每个检测保留类别、置信度和像素框。空`detections`不等同于确定未佩戴。
- `run.json`包含`format_version: 2`、`image_count`、输入清单/指纹、权重哈希、参数及运行状态。旧字段`frame_index`、`source_frame_index`和`images_or_frames`已移除，旧结果按原格式解释。
- 保留重复/遗漏、框/类别/置信度和前后内容检查。逐行先写`.part`，完整通过后发布正式JSONL并写`complete`；失败保留已写结果和失败状态，不能只看文件名认定成功。

当前格式描述保留的检测后端；护目镜最终输出须在任务明确后定稿。
