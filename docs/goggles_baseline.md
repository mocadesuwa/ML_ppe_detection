# 护目镜第一版实施方案

更新日期：2026-10-22。用户已确认只输出头像佩戴状态，采用二分类。数据准备和训练前检查已完成，训练尚未启动；完整处理方案见[数据处理方案](data_processing_plan.md)。

## 当前方案

- 数据：PPEs v7原100张，加SH17作者版本1原80张；226个对象逐项复核，最终191张头像。
- 标签：未佩戴145、佩戴46；普通眼镜、太阳镜、额头佩戴为未佩戴，无法判断排除。
- 划分：显式来源组先合并，再固定train/val/test 133/29/29。所有工厂连续帧同组进入训练，SH17相关系列不拆组，并保证训练中两种来源均有两类。
- 输入：原生RGB头像保留，加载时等比例缩放填充224×224；训练才做温和翻转/颜色变化，验证和测试不增强。
- 模型：ImageNet MobileNetV3 Small，冻结特征骨干，仅训练分类头；参数与来源哈希见[配置](../configs/goggles_classification_v1.yaml)。
- 初始训练计划：AdamW，lr 0.0003，batch 16，最多30轮，验证macro-F1选最佳，patience 8；类别权重仅按训练计数计算。

## 当前停止点

189项累计回归通过，真实分类数据导出、完整性检查和CLI计划已运行。CUDA训练批次前向通过，包含两类，形状16×3×224×224→16×2；模型参数和缓冲区保持不变，梯度更新0、未构建优化器。实际摘要见[训练前状态](pretraining_status.json)。

分类训练入口默认只生成计划，只有另加`--start`才允许拟合，并核对预检报告与当前配置、数据、权重指纹。本轮未执行`--start`；训练循环、反向传播、训练内存、早停和最佳检查点写入尚未实际运行，不把准备完成称为模型完成。

## 下一阶段

用户明确推进训练后才开始拟合；观察训练和验证，按验证macro-F1选择方案；最终确定后只进行正式测试评价，保存混淆矩阵、各类Precision/Recall/F1、Accuracy及失败样本。每个评价集只有5个正例，结果应说明样本限制，不承诺预先编造的效果门槛。

当前复核由Codex逐图完成，未进行独立第二标注者一致性研究；公开来源不能保证所有未知人物关系。实际实验室域覆盖仍需后续检查。
