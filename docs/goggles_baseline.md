# 护目镜第一版实施方案

更新日期：2026-10-22。用户已确认只输出头像佩戴状态，采用二分类。数据准备、两轮短跑和小样本基线已完成；处理方案见[数据处理方案](data_processing_plan.md)，真实结果见[训练与评价报告](goggles_training_report.md)。

## 当前方案

- 数据：PPEs v7原100张，加SH17作者版本1原80张；226个对象逐项复核，最终191张头像。
- 标签：未佩戴145、佩戴46；普通眼镜、太阳镜、额头佩戴为未佩戴，无法判断排除。
- 划分：显式来源组先合并，再固定train/val/test 133/29/29。所有工厂连续帧同组进入训练，SH17相关系列不拆组，并保证训练中两种来源均有两类。
- 输入：原生RGB头像保留，加载时等比例缩放填充224×224；训练才做温和翻转/颜色变化，验证和测试不增强。
- 模型：ImageNet MobileNetV3 Small，冻结特征骨干，仅训练分类头；参数与来源哈希见[配置](../configs/goggles_classification_v1.yaml)。
- 初始训练计划：AdamW，lr 0.0003，batch 16，最多30轮，验证macro-F1选最佳，patience 8；类别权重仅按训练计数计算。

## 实际执行

训练前189项回归和零更新预检保留在[历史快照](pretraining_status.json)。本轮新增14项，203项累计回归通过；两份配置各有匹配CUDA无梯度预检，未安装依赖。

用户确认按[训练流程](classification_training_workflow.md)推进后，实际显式执行短跑2轮18次更新，所有验收通过才开始基线；基线独立从ImageNet初始化，完成11轮99次更新，第3轮验证macro-F1最高0.775194，后续连续8轮未提高触发早停。骨干参数/缓冲区不变、分类头改变，最佳检查点重载logits一致。训练运行峰值已分配显存约76.53MiB；完整哈希、环境和耗时见[训练状态](training_status.json)。默认CLI仍只输出计划，不隐式训练。
