# 图形启动与识别前端

2026-10-28。用户要求为现有项目提供可用前端，解决依赖CMD脚本打开的问题，并明确训练与数据任务全部不在本轮范围内。本次为单一前端实施里程碑，没有新增后续开发阶段。

## 已实施范围

1. 复用现有Python环境、`src.serve_demo`和两类识别契约，增加图形启动器及当前机器的快捷入口。启动器负责自己的子进程、就绪/失败提示、日志、停止/重启与重复打开处理。
2. 继续使用浏览器中的原生HTML/CSS/JavaScript，完善单图上传、完整预览、读取状态、清空、模型选择、识别反馈、连接重试和JSON下载。历史资料仍由原有小按钮展开。
3. 更新使用说明、独立日志、框架说明和交接手册。源代码随本轮Git检查点保存；快捷方式包含绝对路径，只在本机生成。

## 设计与边界

- 视觉方向来自当前Neutral Modern设计系统：浅灰背景、深色正文、钴蓝主操作，桌面双栏、窄屏纵向排列。识别是页面主体，辅助资料默认收起。
- 页面沿用同源外部脚本/样式，不更改服务器的内容安全策略。上传图片保持完整比例，不新增照片、外部素材或联网依赖。
- 启动器使用已有Tkinter与pythonw，服务仍监听`127.0.0.1:8765`、请求GPU0。端口被占用时提示用户处理，不终止其他进程、不改为云端服务。
- 保留已有训练曲线与摘要内容；`training.js`、`training-summary.json`、`src/`、配置、数据集、权重及实验记录均不修改。不执行真实训练、数据准备或封存测试评价，不制作安装包。
