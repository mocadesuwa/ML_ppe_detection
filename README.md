## 第一版方案

先做口罩这一种用品，建议识别三种人脸状态：mask、no_mask、mask_incorrect。实际类别与人脸框规则在原始数据抽查后确定。

模型暂定 YOLO11n 预训练检测模型，imgsz=640，最多 50 轮，batch 初始 8，显存不足时降低。评价包括总体和分类别的 Precision、Recall、mAP50、mAP50–95，以及代表性的失败案例。

这些是计划参数，目前没有训练分数。通用场景数据上的效果也不能直接当作实验室场景效果。

## 已实现的框架结构

```text
项目根目录/
```
