## 第一版方案

先做口罩这一种用品，建议识别三种人脸状态：mask、no_mask、mask_incorrect。实际类别与人脸框规则在原始数据抽查后确定。

模型暂定 YOLO11n 预训练检测模型，imgsz=640，最多 50 轮，batch 初始 8，显存不足时降低。评价包括总体和分类别的 Precision、Recall、mAP50、mAP50–95，以及代表性的失败案例。

这些是计划参数，目前没有训练分数。通用场景数据上的效果也不能直接当作实验室场景效果。

## 框架验证

框架搭建阶段曾完成 8 项测试，覆盖坐标约定、无效框拒绝、相似图片分组、固定划分、转换与校验流程、数据变更后的核查记录失效，以及压缩包解压路径。该阶段全部 CLI 帮助入口及代码编译检查通过，正式训练和短跑的 dry-run 参数解析通过。

2026-10-08 初版保存时使用项目 `.venv` 复查，5 项测试通过，3 项因缺少 Pillow 或临时目录权限报错。后续调整使用已有 Pillow 12.0.0 与 PyYAML 6.0.3 的系统 Python 3.14，以及项目缓存内的临时目录，在正常本机权限下 130 项累计回归测试全部通过。项目 `.venv` 仍未准备完成；本次未安装依赖。

每轮修改后运行以下入口，累计检查坐标转换、分组划分、压缩包路径、合成数据转换校验、数据核查记录失效与标签几何。临时样本在 `.cache/tests/` 中创建，运行结束自动清理；不接触真实数据或调用训练。

解压现在会拒绝覆盖非空目录，先核查条目并在同级临时目录完成读取和 CRC 校验，再移入目标目录。Codex 沙箱限制目录重命名时，需要允许回归测试在沙箱外运行；普通本机运行无需该沙箱授权。

新数据清单记录标签哈希，检查时同时核对划分列表和类别。数据指纹现在也绑定清单及划分文件：这些内容改变后需实际重新核查，再记录新版本。旧清单仍可读取；旧指纹算法保存的核查记录需重新建立，不会自动认可。

YOLO 标签按原始数值校验整数类别及字段范围，避免浮点舍入掩盖无效输入；框边缘保留 `1e-8` 容差，兼容转换程序的八位小数输出。支持空标签与 UTF-8 BOM 文件，错误包含实际行号。

共享 YAML 读取拒绝重复字段，支持 BOM、别名和合并；数据目录字段必须为非空字符串。训练计划会检查必需字段、整数与布尔参数、fraction、实验名称和设备格式，配置错误给出文件或字段提示。两种 `--dry-run` 及全部 8 个 `--help` 入口已复查通过；dry-run 不加载模型或创建运行目录，只验证配置并打印计划。设备是否可用和真实模型参数兼容性仍需后续运行验证。

评价入口在加载模型前检查参数、数据核查记录、训练记录与结果目录冲突；模型类别一致后才创建评价目录。最终测试须使用 `--split test --final-test`，并提供完成的 baseline 记录及记录中的 best/last 检查点；无训练记录仍可探索验证集，结果标明记录缺失。运行前后核对权重哈希和数据指纹，发生变化时不写出指标。新增 23 项评价流程测试使用假模型和临时样本，测试常量不代表真实模型分数。

预测入口先检查本地媒体、参数、权重和结果目录，再加载检测模型；目录只扫描直接包含的媒体文件。逐帧检查来源、尺寸、类别、置信度与框坐标，拒绝检测数组长度不一致或遗漏输入。结果先写 `predictions.jsonl.part`，流结束且输入与权重哈希一致后发布正式 JSONL；`run.json` 记录 running、complete 或 failed 状态及内容来源。只有 complete 记录与正式文件一起才表示完成，失败时可能保留临时或未确认文件。新增 26 项假模型测试通过；本轮预测帮助及 4 项 CLI 错误路径也通过，视频解码和真实模型行为尚未验证。

测试使用临时合成样本，仅验证程序逻辑，不代表真实数据质量或模型效果。训练、评价、预测的 YOLO 运行部分还需安装依赖并用真实数据验证。
